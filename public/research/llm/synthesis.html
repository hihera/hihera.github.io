一页结论

  1. 价格分成三层：顶级档输出 $50（GPT-6 Astra、Claude Fable 5.1）；主力档输出 $6～$20（Opus 5.5、Muse Wonder、Gemini 4 Argon、Kimi、Qwen3.8-Max、Grok 4.7）；低价档输出 $5 以下（GLM-5.3、DeepSeek V4-Pro、MiniMax M3）——国内旗舰普遍只有海外顶级档的十分之一S1
  2. 开放权重格局反转：国内 6 家全部开放权重，DeepSeek、千问、Kimi、智谱、MiniMax 开放的是旗舰或接近旗舰；海外只有 Meta 开放了接近旗舰的 Muse Spark Open，OpenAI、Google、xAI 只开放较小或较旧的模型，Anthropic 不开放S1
  3. 收入向企业和编程集中：Anthropic 年化收入 650 亿美元、OpenAI 约 500 亿美元；国内智谱 API 占收入 86.5%、Kimi API 占七成，MiniMax 开放平台收入增长 7 倍——卖调用正在取代卖项目S1
  4. 用户规模看超级应用：ChatGPT 每周 12 亿、Gemini 10 亿；国内豆包 4.19 亿断层领先，千问一年增长约 50 倍，DeepSeek 同比下降 15%S1
  5. 模型厂商全部下场做 Agent：Codex 与 ChatGPT Work、Claude Code 与 Cowork、Gemini Spark 与 Antigravity、Muse、Grok Bot、DeepSeek Harness、豆包工作、Kimi Agent、Z.ai、MiniMax Code——模型与应用的边界正在消失S1S2

02价格分层

两个变化（分析意见）：一是低价抢量正在结束——Google 宣布 Gemini 4 Argon 12 月起涨价一倍，智谱一季度提价 83%、Kimi K3 定价高于前代；二是海外顶级档维持高价，用最强模型和垂直模型（安全、法律、生命科学）获取溢价。

06中美对比分析意见

海外厂商

  • 闭源旗舰 + 高价顶级档
  • 收入规模大一到两个数量级（数百亿美元级）
  • 超级应用与企业订阅是主要收入
  • 算力投入巨大：OpenAI、Google、Meta 年资本开支数千亿美元级合同或指引

国内厂商

  • 开放权重 + 低价，获取全球开发者
  • 收入规模在数亿到十几亿美元级，增速更快
  • API 与开放平台成为主要收入，项目制占比下降
  • 芯片受限，普遍适配国产算力（昇腾、平头哥）

共同点：都在把模型能力包装成 Agent 产品，都在从“卖 token”走向“卖完成的工作”；能力差距在缩小，差距更多体现在收入规模、算力和全球分发上（分析意见）。

07趋势判断分析意见

  • 100 万上下文成为标配：Anthropic、Google、Meta、DeepSeek、千问、Kimi、MiniMax 的旗舰都支持约 100 万 token。
  • 价格从下探转向分化：低价档继续下探，主力档开始提价，顶级档维持高价。
  • 垂直模型带来溢价：OpenAI 的安全、生命科学、法律模型，智谱的法律模型。
  • 模型更新加速、旧模型加速退役：Kimi K2、MiniMax M2.5 / M2.7 两个月内下线，开发者需要更频繁地迁移。
  • 资本化提速：智谱、MiniMax 上市，Anthropic 递交招股书，OpenAI 推迟到 2027，DeepSeek、Kimi 筹备融资与上市。
  • 算力既是成本也是业务：Google 出租 TPU、SpaceXAI 出租 Colossus，算力本身成为收入来源。

08对 AI 产品团队的启示分析意见

选模型

  • 按任务分层用模型：难任务用顶级档，海量任务用低价档
  • 国产开放模型可大幅降低单位成本，但要评估合规要求
  • 为模型退役预留迁移机制

做产品

  • 模型厂商自营的 Agent 覆盖了通用场景，应用层要找垂直场景
  • 利用开放权重做私有化与行业微调
  • 设计“模型可替换”的架构，降低供应商风险

看商业化

  • 卖调用比卖项目更容易规模化
  • 能力够强就有提价空间
  • 订阅套餐（Coding Plan、Agent Plan）让开发者成本可预期

看风险

  • 上游断供与地缘政策
  • 价格战下的利润空间
  • 厂商估值与股价的剧烈波动
